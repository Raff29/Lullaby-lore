# Lullaby-lore
Status: In Development

## Overview
Lullaby-lore is a web application designed to provide users with a collection of bedtime stories. This project aims to offer a diverse range of stories that can be enjoyed by children and adults alike, providing a unique bedtime experience each night.

## Features
* Collection of Bedtime Stories: Users can access a curated collection of bedtime stories.
* Daily Story Updates: Fresh stories are provided daily to ensure a new reading experience each time.
* User-Friendly Interface: An intuitive and easy-to-navigate interface for all age groups.

## Technical Details
* *Frontend*: React is used to create a dynamic and responsive user interface.
* *Backend*: Django serves as the backend framework, providing robust handling of data and user interactions.
* *Database*: Firebase is leveraged for real-time data storage and synchronization, ensuring fast and reliable access to stories.
